# Glosario — medicina prepagada × agentes de IA
| Término | Definición operativa en el curso |
|---|---|
| Medicina prepagada | Financiamiento de servicios de salud mediante pago anticipado, regulado en Ecuador por ley específica y supervisado por la Superintendencia de Compañías, Valores y Seguros. Validar norma vigente con Legal |
| Afiliado / Beneficiario | Titular del contrato / persona cubierta |
| Preexistencia | Condición diagnosticada antes de la afiliación. El agente la registra, nunca la evalúa |
| Carencia | Plazo antes de que una prestación quede cubierta |
| Deducible / Copago | Parte del costo que asume el afiliado |
| Autorización | Aprobación previa para prestaciones de alto costo |
| Reembolso | Devolución de gastos pagados por el afiliado |
| Red médica | Prestadores con convenio |
| Auditoría médica | Área que evalúa pertinencia clínica. Nunca se automatiza la decisión |
| RN | Asesor comercial de SALUDSA (según denominación interna del proyecto) |
| Isabel (P01) | Agente de ventas conversacional del proyecto SALUDSA (WhatsApp / voz) |
| Pep & Zizu (P02) | Agente de marketing del proyecto SALUDSA (Meta Ads y contenido) |
| Agente de conversión | Subagente HubSpot: avanza etapa del lead |
| Agente de inteligencia de leads | Subagente HubSpot: califica y puntúa |
| Agente de hiperpersonalización | Subagente HubSpot: adapta mensaje por perfil |
| LOPDP | Ley Orgánica de Protección de Datos Personales (Ecuador, 2021). Datos de salud = datos sensibles |
| Dato sensible | Requiere consentimiento explícito y controles reforzados |
| Mínimo acceso | El agente ve solo lo que necesita para su tarea |
| Humano en el bucle | Persona aprueba antes de una acción irreversible |
| Acción irreversible | Enviar mensaje a cliente, cambiar etapa de CRM, emitir documento, cobrar |
| Inyección de prompt | Texto en datos que intenta dar órdenes al agente |
| Fallo silencioso | Respuesta fluida y errónea |
| RCTFX | Rol, Contexto, Tarea, Formato, eXamples |
| Eval | Casos + salida esperada + criterio + resultado |
| Línea base | Medición del proceso antes de automatizar |
| Skill | Procedimiento empaquetado que el agente carga cuando corresponde |
| Subagente | Instancia especializada con prompt y herramientas propias |
| MCP | Protocolo para conectar agentes a sistemas (HubSpot, Drive, Slack…) |
| RAG | Recuperación de fragmentos de la KB para responder con fuente |
| KB aprobada | Base de conocimiento validada por Comercial + Legal, con versión y vigencia |
| Supervisión de agente | Revisión periódica de conversaciones reales contra el eval |
| Tasa de escalamiento | % de conversaciones que el agente deriva a humano. Se mide, no se adivina |
| Show & Tell | Cierre público: demo de 3 minutos con un número antes/después |
